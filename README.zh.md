# @guowenzhang/dsh-ui-beautify

[English](<README.md>) | 中文

为 [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) 提供字体、输入框动效、快捷回复、品牌自定义与手机布局优化的第三方插件。

## 优化列表

- **正文与代码字体**：两类字体独立选择，提供思源黑体、思源宋体、霞鹜文楷、Inter、JetBrains Mono、Fira Code 等。正文字体默认思源黑体，代码字体默认系统字体；选择「系统默认」恢复宿主字体，不需要卸载插件。
- **字体按需缓存**：只下载页面实际需要的字符分片，已缓存文件可离线使用。设置页显示字体说明、缓存大小与分片数量，刷新页面（F5）可重新统计。
- **输入框动效**：输入框上方的骑车动画随助手输出速度变化，输出停止后用 8 秒滑行至停住。支持「跟随浏览器」「始终播放」「关闭」，默认尊重浏览器的减少动效偏好。
- **PC 端快捷回复**：输入框下方默认提供「继续」「OK」「没有理解」「现在什么情况」，随界面语言切换；点击在光标处插入并提交，不替换已有草稿，模型忙碌时排队发送。设置页可即时开关，手机端始终隐藏。
- **品牌自定义**：在设置页上传欢迎页 Logo、左上角图标，并修改左上角名称、欢迎页标语。图片支持最大 2 MB 的 PNG、JPEG、WebP、GIF；恢复默认图片或清空文字即可使用内置内容。
- **手机布局**：视口宽度不超过 600px 时，左侧栏变为抽屉，会话保持全宽；左上角展开按钮与右侧栏入口对齐。选择会话或页面、点击遮罩、按 Esc 可收起；右侧栏保留宿主全屏面板，收起后恢复入口。设置控件窄屏堆叠，正文／输入框左右留白为 16px／8px，桌面布局不变。
- **最近对话切换**：已开始的会话顶部最多显示 5 个最近对话，每个标签最多 5 个字，按活动时间排序，点击不置首；排除已归档、空白和子代理对话，不补空位。标签复用宿主字体、选中下划线和状态圆点，实时显示等待审批／计划待审／等待回答、运行中（含子智能体）及未读完成提醒，空闲时无圆点。桌面位于「对话／轨迹」后，手机仅显示可横向滚动的最近对话，并隐藏顶部打开文件和日志／反馈菜单。
- **远程设置同步读取**：手机和其他远程页面读取与桌面相同的宿主脱敏设置，不新增手机配置；设置变更、重连和返回页面时刷新。远程表单保持只读，请在本机端修改和保存。

## 安装

先安装并运行 DeepSeek Harness **0.2.0-rc.1 或更新版本**，再将插件添加到需要使用的 profile。下面以 `web` 为例；其他 profile 请替换名称。

### 从 npm 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-ui-beautify
```

已发布的版本见 [npm 包页面](https://www.npmjs.com/package/@guowenzhang/dsh-ui-beautify)。

### 从 GitHub 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add https://github.com/zhang-guo-wen/dsh-ui-beautify.git
```

安装或升级后，**重启对应宿主并硬刷新浏览器（Ctrl+F5）**，然后打开 **设置 → 界面美化**。普通手机地址刷新后即可使用，无需额外手机插件、布局 URL 参数或修改 Harness 源码。

### 卸载

```sh
npx @deepseek-ai/dsh plugin --profile web remove @guowenzhang/dsh-ui-beautify
```

### 本地开发

```sh
npm ci
npm run typecheck
npm run build
npm test
```

本地目录安装、完整字体表与排查说明见 [维护指南](https://github.com/zhang-guo-wen/dsh-ui-beautify/blob/master/AGENTS.md)。

## 注意事项

- **兼容性**：DSH 仍在快速迭代，宿主升级可能带来兼容性变化；本插件从宿主解析运行时依赖，不替换宿主。已有原生手机抽屉／最近对话条时保留宿主实现及其断点（恰好 600px 时可能不同）。与 dsh-pocket 2.10.6 共用时，仅替换不兼容的手机导航插槽和样式，代理、二维码及设置保留，额外手机文件／日志快捷按钮不挂载。
- **首次字体下载需要宿主联网**：浏览器只访问 DSH 自身，由宿主从镜像下载；浏览器能联网不代表宿主能下载。仅已缓存的文件可离线使用，未缓存的新字符仍可能需要下载。失败时使用回退字体，不影响界面使用。
- **代码字体覆盖范围**：提供的自定义代码字体中只有 Maple Mono CN 覆盖中文，其全部分片约 9 MB，使用 jsDelivr；其他四款中文回退到宿主字体。集成终端和队列面板中硬编码字体的位置不会完全跟随字体设置。
- **设置与缓存**：设置保存在当前 profile 的配置中，页面内修改通常立即生效；新增设置字段需要重启宿主，镜像列表与缓存目录改动也需要重启。字体缓存默认在 `$DSH_HOME/cache/ui-beautify/fonts`，上传图片在 `$DSH_HOME/assets/ui-beautify`。
- **快捷回复会直接发送消息**：已有草稿会与插入的短语一起提交；提交锁定时标签禁用，空白欢迎页不显示标签。设置页不提供短语内容编辑，如需自定义，可在当前 profile 配置的 `ui-beautify` 行中设置 `quickReplies`（最多 4 条，每条最多 40 字），详见 [维护指南](https://github.com/zhang-guo-wen/dsh-ui-beautify/blob/master/AGENTS.md)。
- **动画不是精确测速**：骑车速度按输出字符增长估算，不等同于状态栏的 `tok/s`，不读取用户输入，也不发送数据。
- **远程访问仍只读**：同步读取仅覆盖共用设置表单，不覆盖自有接口或浏览器本地存储；不会开放密钥读取、配置文件打开、插件安装或其他仅本机操作。
- **品牌范围**：品牌自定义作用于 DSH 浏览器界面，Electron 安装版单独打包的原生首次引导窗口不加载此插件。
