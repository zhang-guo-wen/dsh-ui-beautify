# @guowenzhang/dsh-ui-beautify

[English](<README.md>) | 中文

为 [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) 提供字体、输入框动效、快捷回复、品牌自定义与手机布局优化的第三方插件。

插件列表的显示名称与介绍支持英文和中文，随 Harness 语言设置显示，英文为默认回退；英文名称为去掉 npm scope 的原包名，中文名称说明用途，安装仍使用不变的真实包名。

## 优化列表

- **正文与代码字体**：两类字体独立选择，提供思源黑体、思源宋体、霞鹜文楷、Inter、JetBrains Mono、Fira Code 等。正文字体默认思源黑体，代码字体默认系统字体；选择「系统默认」恢复宿主字体，不需要卸载插件。
- **字体按需缓存**：只下载页面实际需要的字符分片，已缓存文件可离线使用。设置页显示简短字体说明与缓存大小。
- **输入框动效**：输入框上沿的固定 1px 光柱随助手实际输出速度流动，直接覆盖输入框上边框，不占额外高度或间距，不影响布局；输出停止后用 8 秒减速至停住，空闲时保持可见并静止悬浮。设置页提供单一开关，默认开启；开启对应始终播放，关闭隐藏光柱，不受浏览器减少动效偏好影响。
- **PC 端快捷回复**：输入框下方默认提供「继续」「OK」「没有理解」「现在什么情况」，随界面语言切换；点击在光标处插入并提交，不替换已有草稿，模型忙碌时排队发送。标签**始终排成一行**：窗口变窄时从末尾依次少显示几条，不换行堆到第二行，变宽后自动补回来。设置页可即时开关，手机端始终隐藏。
- **回到提问**：阅读长回答时，浮动向上按钮可回到你最近一条已发送消息的位置，从头阅读后续 AI 回答；原有向下按钮仍可跳到最底部。电脑和手机均可使用，设置页可即时开关。
- **品牌自定义**：在设置页上传欢迎页 Logo、左上角图标，并修改左上角名称、欢迎页标语。图片支持最大 2 MB 的 PNG、JPEG、WebP、GIF；恢复默认图片或清空文字即可使用内置内容。
- **手机布局**：视口宽度不超过 600px 时，左侧栏变为抽屉，会话保持全宽；左上角展开按钮与右侧栏入口对齐。选择会话或页面、点击遮罩、按 Esc 可收起；右侧栏保留宿主全屏面板，收起后恢复入口；宿主弹窗始终显示在抽屉和全屏编辑器上方，避免隐藏弹窗拦截触摸。设置弹窗改为顶部标题与关闭按钮、可横向滑动的分类导航和全宽可滚动内容；下拉与文字输入窄屏堆叠，开关与说明并排，避免文字逐字换行和横向溢出。正文／输入框左右留白为 16px／8px，桌面布局不变。与 Pocket 共用时，文件改动卡片的复制按钮与文件名、增删统计同排，长路径省略显示，复制逻辑不变。
- **最近对话切换**：已开始的会话顶部最多显示 5 个最近对话，每个标签最多 5 个字，按活动时间排序，点击不置首；排除已归档、空白和子代理对话，不补空位。标签复用宿主字体、选中下划线和状态圆点，实时显示等待审批／计划待审／等待回答、运行中（含子智能体）及未读完成提醒，空闲时无圆点。桌面位于「对话／轨迹」后，手机仅显示可横向滚动的最近对话，并隐藏顶部打开文件和日志／反馈菜单。
- **远程设置同步读取**：手机和其他远程页面读取与桌面相同的宿主脱敏设置，不新增手机配置；设置变更、重连和返回页面时刷新。远程表单保持只读，请在本机端修改和保存。

## 功能开关

打开 **设置 → 界面美化 → 界面增强**，可分别控制 **回到最近提问**、**手机端适配**、**最近对话切换**、**远程设置同步读取**。每项都有功能说明，**默认开启**，旧配置未填写时也保持开启。

- 关闭回到最近提问会隐藏向上按钮，原有向下按钮不受影响；重新开启立即恢复。
- 关闭手机端适配会移除本插件的抽屉、留白、手机工具栏与设置页布局覆盖，包括美化设置控件堆叠和触摸输入尺寸，恢复原有布局。最近对话由独立开关控制；快捷回复及其设置行在手机端仍始终隐藏。
- 关闭最近对话切换会移除本插件的标签和相关样式，恢复宿主视图标签栏；不关闭手机抽屉，不修改会话数据。宿主自带的最近对话条不受影响。
- 远程设置同步读取请在本机端开关。远程页面启动时读取一次脱敏设置以确认开关；关闭后停止插件同步和刷新监听，恢复宿主原有读取行为。重新开启后刷新远程页面。远程始终只读，不开放密钥或写入权限。

开关保存在当前 profile 的 `ui-beautify` 配置中（`scrollToPromptEnabled`、`mobileLayoutEnabled`、`recentSessionsEnabled`、`remoteSettingsEnabled`）。升级首次需要重启宿主并刷新页面以加载新增字段，之后本机开关即时生效。

## 描述翻译

打开 **设置 → 界面美化 → 界面增强 → Skill 与插件描述**，点击 **翻译描述**。使用宿主配置的默认模型翻译为当前界面语言；只处理描述，不翻译完整技能指令，不发送当前会话或工具，也不修改原始文件。

- 成功译文按来源、原始描述和目标语言持久化；重复点击、刷新、重启或描述未变的升级直接复用。原文改变后，再次点击仅补齐新描述；失败项可重试。已有官方语言资源优先使用。
- 译文用于插件列表／详情和 skill 斜杠菜单；支持的 skill 文件预览及调用卡片附加译文摘要，原文件与历史工具结果保持原样。界面语言切换后使用对应缓存，没有缓存时保留原文，不自动调用模型。
- 一次模型请求批量翻译多条描述：先跳过缓存，按 UTF-8 字节合并，输入（含 JSON 与翻译指令）超过 16 KB 才拆批，不逐条调用。界面保留默认提供方／模型／推理档位，分别显示「插件、Skill、工作区 Skill」已完成／总数，不显示批次或字节限制说明。翻译中按钮变为可点击的「取消」；取消会中止当前请求并停止后续批次，已保存译文保留。
- Skill 范围包含宿主全局已加载目录、所有已登记工作区通过 Skill 服务发现的项目目录，以及当前会话的 Agent 专属目录。相同来源去重，同名不同文件分别保存；插件数按已安装或启用的包统计，组件描述另计入翻译总数。工作区读取失败会提示，未登记项目不扫描。展示时仍按当前会话解析，避免同名技能串译。
- 译文保存在 `$DSH_HOME/data/ui-beautify/description-translations/v1`，独立于插件安装目录。模型调用需要联网，消耗默认模型额度，选中的描述会发送给该提供方。
- 更新此功能后需要重启宿主并刷新页面。缺少翻译服务或默认模型时显示不可用，不影响其他美化功能。

## 安装

先安装并运行 DeepSeek Harness **0.2.0-rc.1 或更新版本**，再将插件添加到需要使用的 profile。下面以 `web` 为例；其他 profile 请替换名称。

### 从 npm 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-ui-beautify
```

已发布的版本见 [npm 包页面](https://www.npmjs.com/package/@guowenzhang/dsh-ui-beautify)。

### 从 GitHub 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add https://github.com/zhang-guo-wen/dsh-ui-beautify.git
```

安装或升级后，**重启对应宿主并硬刷新浏览器（Ctrl+F5）**，然后打开 **设置 → 界面美化**。普通手机地址刷新后即可使用，无需额外手机插件、布局 URL 参数或修改 Harness 源码。

### 卸载

```sh
npx @deepseek-ai/dsh plugin --profile web remove @guowenzhang/dsh-ui-beautify
```

### 本地开发

```sh
npm ci
npm run typecheck
npm run build
npm test
```

本地目录安装、完整字体表与排查说明见 [维护指南](https://github.com/zhang-guo-wen/dsh-ui-beautify/blob/master/AGENTS.md)。

## 注意事项

- **兼容性**：DSH 仍在快速迭代，宿主升级可能带来兼容性变化；本插件从宿主解析运行时依赖，不替换宿主。已有原生手机抽屉／最近对话条时保留宿主实现及其断点（恰好 600px 时可能不同）。与 dsh-pocket 2.10.6 共用时，仅替换不兼容的手机导航插槽和样式，代理、二维码及设置保留，额外手机文件／日志快捷按钮不挂载。
- **首次字体下载需要宿主联网**：浏览器只访问 DSH 自身，由宿主从镜像下载；浏览器能联网不代表宿主能下载。仅已缓存的文件可离线使用，未缓存的新字符仍可能需要下载。失败时使用回退字体，不影响界面使用。
- **代码字体覆盖范围**：提供的自定义代码字体中只有 Maple Mono CN 覆盖中文，其全部分片约 9 MB，使用 jsDelivr；其他四款中文回退到宿主字体。集成终端和队列面板中硬编码字体的位置不会完全跟随字体设置。
- **设置与缓存**：设置保存在当前 profile 的配置中，页面内修改通常立即生效；新增设置字段需要重启宿主，镜像列表与缓存目录改动也需要重启。字体缓存默认在 `$DSH_HOME/cache/ui-beautify/fonts`，上传图片在 `$DSH_HOME/assets/ui-beautify`。
- **快捷回复会直接发送消息**：已有草稿会与插入的短语一起提交；提交锁定时标签禁用，空白欢迎页不显示标签。设置页不提供短语内容编辑，如需自定义，可在当前 profile 配置的 `ui-beautify` 行中设置 `quickReplies`（最多 4 条，每条最多 40 字），详见 [维护指南](https://github.com/zhang-guo-wen/dsh-ui-beautify/blob/master/AGENTS.md)。
- **动画不是精确测速**：光柱速度按输出字符增长估算，不等同于状态栏的 `tok/s`，不读取用户输入，也不发送数据。
- **远程访问仍只读**：同步读取仅覆盖共用设置表单，不覆盖自有接口或浏览器本地存储；不会开放密钥读取、配置文件打开、插件安装或其他仅本机操作。
- **品牌范围**：品牌自定义作用于 DSH 浏览器界面，Electron 安装版单独打包的原生首次引导窗口不加载此插件。
