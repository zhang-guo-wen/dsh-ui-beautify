# @guowenzhang/dsh-ui-beautify

[English](<README.md>) | 中文

## 背景

这是一个为 [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) 做界面优化的第三方插件，重点是**手机端适配**：让对话、侧栏和设置页面在小屏幕上更好用。

同时支持分别选择正文与代码字体，自定义 Logo、图标、名称和欢迎标语，以及使用默认模型把 Skill、插件等英文描述翻译成当前界面语言，方便使用和阅读。另有最近对话切换、逐轮向上跳的提问按钮、悬浮显示本轮提问开头的简短一行文字、输入框光柱和 PC 端快捷回复等小改进。

设置页的每一项都会报告自己的保存结果：保存中、已保存，宿主拒绝时给出重试入口。名称和标语输入框会等输入法组合结束再提交，确认候选词不会只存半句。

在缺少最新 JavaScript API 的手机浏览器上，插件会补齐 PDF 引擎需要的那几个 API，因此 PDF 与 Word/PowerPoint 预览能正常打开，而不是报 `... is not a function`。

## 安装

需要 DeepSeek Harness **0.2.0-rc.1 或更新版本**。以下以 `web` profile 为例：

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-ui-beautify
```

安装后重启对应宿主并刷新浏览器，在 **设置 → 界面美化** 中使用。描述翻译需点击「翻译描述」，消耗默认模型额度，译文会缓存且不修改原始文件。

共享同一本机数据目录的宿主进程会合并重复翻译请求，持锁进程退出后可恢复；未知锁保留、不猜测删除。恢复协议保留少量世代标记目录，防止暂停的旧进程误取新锁；任何宿主仍在运行时均不要清理这些标记。

## 最近对话

最近对话在 **设置 → 界面美化** 中有独立开关，不依赖代码工作视图或手机适配。标签按活动时间显示最多五条符合条件的对话，点击不会置首。标签使用宿主主题 token，浅色、深色以及宿主没有对话／轨迹标签栏时均有完整样式。

桌面端是一条麻绳：两端钉在标题区左右边缘，最多五条最近对话用衣夹夹在绳子中段，当前对话着色，绳子向中间自然下垂。绳子与宿主的对话／轨迹标签同排，后者仍可正常点击；标题区高度按绳子这一行增加。标题区变窄时吊牌先缩小、再落到宿主标签下方单独一行，两种情况下绳子仍然连到左右两边。宽度不超过 600px 时手机端保持原来的文字标签样式，并隐藏宿主视图标签。宿主自带的最近对话栏优先显示。关闭最近对话或卸载插件时，移除插件标签栏并恢复宿主标签与标题区高度。

开发时可运行 `npm run test:recent`，覆盖列表／状态单测与 1200、601、600、393px 的真实 Chrome／React fixture，包括标签栏延迟出现、并排／换行两种挂法、会话切换和清理。测试使用现有 desktop profile 的 Playwright 与本机 Chrome，也可通过 `DSH_MOBILE_PLAYWRIGHT`、`DSH_MOBILE_CHROME` 指定安装位置；不会启动或修改正在运行的 DSH 宿主。

## 未读会话

某个会话在你查看别的会话时完成，侧栏会给它标记一个绿点。现在打开这样的会话会停在最后一条回答的开头，而不是对话底部，可以像看新消息一样从头读。落点会等宿主恢复完会话再定位，阅读缩进与导航控件一致；一旦你自己滚动，插件就不再干预。开关「未读会话停在回答开头」位于 **设置 → 界面美化 → 界面增强**，默认开启。

## 快捷操作悬浮按钮

打开的对话右下角会浮着一个可拖动的按钮：位置记在浏览器里，刷新后仍在；默认停在输入框上方而不是压住发送按钮，可以拖到窗口内任意位置。点一下弹出宿主的菜单，对当前对话提供三个快捷操作：

- **归档当前会话** —— 调宿主的归档动作；归档成功后自动切到下一个会话（与「下一个会话」同一优先级），不会停在新建会话页；会话还在运行时该项禁用并说明原因。
- **置顶当前会话／取消置顶当前会话** —— 跟着宿主自己的置顶状态走，与侧栏的置顶标记一致。
- **下一个会话** —— 按三档优先级切换：先找未读绿点（离开期间完成、还没读的对话），没有绿点就找下一个置顶（收藏）会话，两者都没有就按对话时间找当前会话之后的下一个更旧会话（最旧时绕回最新）。前两档按侧栏顺序往后走、到末尾绕回；都没有其他会话时该项禁用并说明。

每个动作都走侧栏用的同一个 Workspace 服务，所以侧栏、绿点和这个按钮的读数永远一致。操作失败会在菜单里说明，不会无声消失。开关「快捷操作悬浮按钮」位于 **设置 → 界面美化 → 界面增强**，默认开启。

## 运行提示

回答生成过程中，对话底部会显示一行带图标的提示。**设置 → 界面美化 → 运行状态** 可以把这两部分分别换掉：

- **运行提示文字**：替换「深度求索中」这句话，其后的已用时间保持不变（例如「思考中，用时 29 秒 ···」）。留空恢复宿主的原文案。
- **替换运行图标**：打开后把宿主的鲸鱼尾巴换成下方的图标；没有上传图片时使用内置的转圈动画，它跟随主题文字颜色，并在系统的减少动态效果设置下放慢。
- **运行图标**：上传动画 PNG、WebP 或 GIF，显示在提示文字前。上传后会自动打开上面的开关；清掉图片即回到内置动画。

文字与图标都是实时生效的：正在生成的那一行会在下一次重绘时跟着变，不需要重启或刷新。宿主的已用时间每秒重写同一行文字，插件在每次重写后重新套用替换。

## 界面精简

**设置 → 界面美化 → 界面精简** 收起部署方不希望用户进入的入口：隐藏设置页头部的**打开配置文件**操作，在设置导航中隐藏**内置插件**与 **Agent 预设**两个页面，并把侧栏的**插件**与**自动化任务**两行收进设置导航——点开对应行就跳到它指向的页面。当通用设置里的**代码工作工具**关闭时，还会一并隐藏新会话页的 Agent 预设选择器和对话标题旁的预设标签。被隐藏的设置页面与迁移的侧栏入口仍然照常组合，只是行换了位置；关掉这个开关后，宿主原本的每一项入口都会恢复。

同一页还可以用独立开关**隐藏输入框下方的统计**收起输入框下方的三项读数：轮次与速度、Token 消耗与缓存命中、宿主的上下文占用环。它上面的开关互不影响，关掉后三项读数都会恢复显示。

同一组里还有两个开关把输入框底行收干净：**隐藏模型选择**与**隐藏访问模式**。二者互相独立、**默认关闭**，新装插件仍显示宿主原本的模型选择器与访问模式；需要更安静的输入框时由用户手动打开，关掉其中一行只会恢复对应那个宿主座位。模型与访问模式/权限仍可用宿主自己的 **/model** 与 **/permission** 命令切换。

## 上下文进度圈

输入框的主按钮（发送与中断共用的那个）外圈有一道细进度环，显示当前上下文窗口已用掉多少。读数来自宿主自己的上下文压力投影，公式与宿主的上下文占用表一致，两处不会给出不同数字；进度用主题的业务色、底环用边框色 token，画在按钮外侧，不改变布局也不拦截点击。它在 **设置 → 界面美化 → 界面增强** 中有独立开关，与隐藏下方统计的开关互不影响：收起输入框下方的统计时，进度圈照常显示。

### 2. 手机端适配

以下使用同一个演示会话、相同的 **393 × 844** 手机视口截图。左侧关闭本插件的手机适配与最近对话开关，右侧开启；设置页对比仅切换手机适配。图中编号标注主要区别。

#### 对话界面对比

![手机对话界面适配前后对比及区别标注](<docs/images/mobile-conversation-comparison.zh.png>)

1. **侧栏不再挤占对话宽度**：固定图标栏改为左上角抽屉入口。
2. **切换对话更方便**：顶部显示最近对话；此功能有独立开关。
3. **阅读与输入更宽松**：正文和输入框使用适合手机的宽度与留白。

#### 设置页面对比

![手机设置页面适配前后对比及区别标注](<docs/images/mobile-settings-comparison.zh.png>)

1. **分类导航横向排列**：不再占用左侧内容空间，可左右滑动切换分类。
2. **内容区域全宽显示**：减少文字被挤窄和频繁换行。
3. **控件适合触摸**：字体选择等控件堆叠排列，关闭按钮保留在顶部。
