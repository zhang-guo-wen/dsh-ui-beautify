# @guowenzhang/dsh-ui-beautify

[English](<README.en.md>)

## 背景

**让手机端也好用。**

这是给 DeepSeek Harness 做界面优化的第三方插件，重点是手机端适配：对话、侧栏和设置在窄屏上不再被挤成一团。外观上还能分别选正文字体与代码字体、自定义品牌，并把 Skill、插件等英文描述翻译成界面语言。

## 截图

**手机对话**：同一会话、同一视口，左侧关闭手机适配，右侧开启。

![手机对话界面适配前后对比](<docs/images/mobile-conversation-comparison.zh.png>)

**设置**：手机适配、最近对话与描述翻译都在 **设置 → 界面美化**。

![设置页的界面增强分组](<docs/images/settings-enhance.png>)

## 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-ui-beautify
```

装完重启宿主并刷新浏览器，打开 **设置 → 界面美化**。

## 特点

1. **手机端布局**：固定图标栏收成左上角抽屉按钮，正文与输入框使用适合手机的宽度，设置页分类横向滑动、内容占满全宽。
2. **正文字体与代码字体**：两类字体分别选择，字体按需下载到本机缓存，之后离线可用。
3. **品牌与运行提示**：自定义 Logo、图标、名称和欢迎标语，也能替换回答生成时的提示文字与动画图标。
4. **描述翻译**：用默认模型把 Skill、插件等英文描述翻成当前界面语言，译文缓存，原始文件不动。
5. **界面精简与快捷操作**：隐藏不需要的设置入口和输入框下方的统计；另有最近对话、未读会话停在回答开头、右下角快捷操作按钮。
